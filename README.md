## Featured projects

### [RepoReady](https://github.com/clindelof/RepoReady)

A privacy-first publication gate for Git repositories. It identifies
disclosure risks, history leaks, dependency concerns, and project-readiness
issues without exposing suspected secret values.

### [RepoReady Viewer](https://github.com/clindelof/RepoReadyViewer)

An Angular application for exploring RepoReady JSON and SARIF reports.
Reports are processed entirely in the browser through a responsive,
accessible findings dashboard.

[View the live application](https://clindelof.github.io/RepoReadyViewer/)

### [Repeatable Dates](https://github.com/clindelof/RepeatableDates)

A dependency-free Python library for generating recurring dates, including
business-day adjustments, holiday calendars, exceptions, collision policies,
and advanced recurrence rules.
